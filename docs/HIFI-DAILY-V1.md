## 唯一近期目标

以现有 MoKee 为基础，交付能离开电脑日常使用的播放器：最小且正式目标构建的 HiFi HAL、普通应用快捷开关、左侧通知区真实状态、安全独立 DAC 音量及回退。48k 为本次验收基线；44.1/native/SRC 与完整专用系统后续继续，不取消。

## 顺序和完成标准

1. 安全与协议：恢复 205 必须有双声道回读；失败不得清除待恢复状态；关闭、退出和新 HAL 会话可恢复。schema4 采用一个外层键和不冲突的内层分隔符；截断、坏输入和陈旧证据关闭功能。
2. 操作可靠性：部署和回退的读回失败必须失败；验证文件哈希、属性、挂载只读、进程身份及映射，空跑断言失败必须返回非零。
3. 普通应用：开关和显式音量提交有回读，通知使用公共 API；异常退出、过期或失去路由证据不遗留 HIFI 工作标志。暂停/备用不能显示实际工作中。
4. 正式构建：锁定完整依赖、源提交、工具链和产品配置；只构建目标 HAL 模块，核对 ABI/依赖/运行特性。诊断构建不升格。
5. 设备验收：安全条件下验证开关、音量与恢复、进程重启、待机与播放稳定性、耳机插拔和开机恢复，保存可核查证据和明确的回退说明。人工听音与物理插拔不能用软件模拟冒充。
